# Rice Purchase & Sales Register

Bilingual Odia + English PWA for GitHub Pages.

## Current setup

- Google Apps Script API is preconfigured.
- Only one rice type is used: **Normal Rice (R001)**.
- Party / Customer names are managed from the app's Parties section.
- Purchase and Sales forms automatically use Normal Rice.

## GitHub Pages

Upload the files to a GitHub repository, then enable **Settings → Pages → Deploy from branch → main → / (root)**.

## Files

- `index.html`
- `manifest.json`
- `service-worker.js`
- `README.md`

## Rice type
The app is configured for one fixed rice type only: **NORMAL RICE (R001) / ସାଧାରଣ ଚାଉଳ**. Purchase and Sales forms do not require rice selection.
